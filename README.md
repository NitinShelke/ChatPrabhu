# 🧱 Python Project Template

A clean, reusable, and scalable Python project structure.
Ideal for general-purpose Python applications, data projects,
and development best practices.

---
Requiremetns:
Python>=3.12
UV package manager to be installed.

## Setup in 5 Steps

1. **Clone the Repository**
    git clone [chatPrabhu Repository](https://github.com/NitinShelke/chatPrabhu)

    cd chatPrabhu

2. change the name of project as per your choice and modify the same in pyproject.toml
3. add the required packages to pyproject.toml

4. **Create Virtual Environment**
   use commands :
   1. uv sync
5. **Install Dependencies**
     1. uv pip install -e .["dev"]
     2. pre-commit install
